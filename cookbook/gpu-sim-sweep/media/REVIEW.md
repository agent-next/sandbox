# media/REVIEW.md — what was checked before committing the media

All media was generated by `bash media/make_media.sh` on 2026-10-15 from
`media/data/report.json` — the exec report of a real
`python3 run.py --gpu` run on fresh lease `gl-3f66cf-7` (full output in
`media/data/gpu-run.log`; numbers cross-checked in `RECEIPT.md` run 2).
Nothing is hand-edited.

Environment: matplotlib 3.10.8 + numpy 2.4.3 in `media/.venv`
(git-ignored), ffmpeg 6.x (`ffmpeg -version` at encode time), Python 3.12.

## 1. Images opened at full size

**result.png** (2 panels, 2400×920 at 200 dpi):

- Left: measured GPU steps/s vs nworld on log-log axes — 122 / 7,116 /
  60,842 / 222,929 / 557,066 for nworld 1 / 64 / 512 / 2048 / 8192, each
  point labelled. The measured CPU baseline (35,681 steps/s, dashed
  orange) and the ×4 pass floor (142,724 steps/s, dotted pink) are drawn
  on it; the ladder crosses the floor between nworld=512 and 2048. Axis
  labels with units, legend, suptitle: nothing clipped or overlapping.
- Right: box z range per nworld after the settle window — all ranges sit
  inside the green landed band [0.255, 0.525] m, tight around the table
  top line at 0.275 m (resting box centre = 0.315 m). The text box reads
  "all worlds finite; arm err max 0.036 rad < 0.15" and "CPU<->GPU
  world-0 parity err 0.0081 rad < 0.05" — all from the verdict.

**loop.png** (2 panels, 2400×920 at 200 dpi):

- Left: gate × artifact matrix. Good row: all six gates "ok". Every
  mutant row shows the real killing gate(s) in red — `smuggled_results`,
  `gravity_flipped`, `missing_nconmax` at structure; `tiny_timestep`,
  `short_settle` at cost; `solver_iter_1` at cpu-parity; `low_capacity`
  at physics-oracle + cpu-parity; `over_ladder` at physics-oracle +
  throughput. Grey cells are gates the judge never reached (the grade
  exits on the first failing gate class). Matches the run-2 log exactly.
- Right: kill-rate bar, 8/8 = 100% killed, 0 survived.

## 5. Regeneration is reproducible

`make_media.sh` re-derives everything from `data/report.json` (it dies
naming the missing field if the report is absent or incomplete). The
report itself is regenerated by
`python3 run.py --gpu --report-json media/data/report.json`.
`media/master/` (crf-0 master), `media/.frames/` and `media/.venv/` are
git-ignored.
