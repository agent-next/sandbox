# REVIEW — firmware-qemu media

How the media was produced and what was checked by eye. All inputs come
from real judge runs; `media/collect_data.sh` regenerates `media/data/`.

## Provenance of the numbers

- `media/data/verdict-*.json` — real `judge/grade.sh --seed 20260814
  --json` output for `examples/good` and for each of the 14 artifacts
  generated by `judge/mutants.py make-all`. Every gate value drawn in
  the figures is the `detail` string from these files.
- `media/data/uart-good.json`, `media/data/uart-crc-poly.json` — real
  UART transcripts captured by `media/capture.py`, which imports the
  judge's own `judge/drive.py` (same `Session`/pty code, same QEMU argv,
  same `judge/spec.json`, same seed) and records each wire event with a
  timestamp. The judge itself was not modified.
- `media/data/size-good.txt` — real `arm-none-eabi-size -A` output on
  the ELF the toolchain built; `media/data/firmware-good.map` — the
  linker map from that build (FLASH/SRAM region limits parsed from its
  `Memory Configuration` block).
- `media/data/selftest.log` — real `judge/selftest.sh` output:
  14/14 killed, 13 behavioural + 1 build-only, behavioural kill rate
  100 %.
- `media/data/loop.json` — the replayed fix sequence (bad -> partly
  fixed -> good). It only orders verdict files that already exist; the
  figures and video label it as a replay, not a live agent trace.

## What was checked by eye

- `result.png` opened at full size: terminal column is the real
  transcript (banner + first 12 exchanges), the elision marker states
  the true remaining count (49 exchanges) on two wrapped lines inside
  the panel, every gate row shows its measured detail with the
  separator BELOW the rule text (not striking through the next gate
  name), header-to-first-row gap is clear, the `maps_ok` bar shows
  2224 B against the red 8192 B pass line, FLASH 2744/262144 B and
  SRAM 4456/65536 B are drawn under it, and the bottom bar draws one
  tick per real transaction (61, all green). `check_no_overlap` and
  `check_inside_axes` ran inside the generator; no clipped or
  overlapping text seen.
- `loop.png` opened at full size: 15 rows x 8 gates readable; red cells
  carry the measured values from the verdict JSONs (`7/46 wrong`,
  `5/46 wrong`, `!= zlib`, `no banner 10s`, `make exit 2`, `no ELF`,
  `skipped`); the `build-broken` row is amber and labelled build-only;
  the replayed sequence and the 14/14 kill-rate line appear at the
  bottom. `check_no_overlap` ran; nothing overlaps.
- `demo.mp4` frames extracted with `ffmpeg -ss <t> -frames:v 1` and
  opened at full size at t = 4, 15, 30, 40, 45, 50 s:
  - t=4 title card;
  - t=15 good session scrolling (banner, HELP/ECHO/ERR exchanges, RB
    commands, seeded CRC commands — all real lines from the capture);
  - t=30 good session continuing;
  - t=40 the crc-poly mutant session with wrong CRC responses in red
    and `!= want: OK 0x...` annotations taken from the real failure
    list, plus the explicit `· · · (+0.8s quiet on the wire)` time
    marker;
  - t=45 mutant terminal box: no overflow below bottom border — every
    rendered line (including `!= want:` sub-lines and "quiet on the
    wire" markers) counts toward MAXROWS, long `> CRC 000...` lines
    are truncated with `…` at box edge;
  - t=50 verdict panel (8/8 gates with details, replayed fix sequence
    labelled "not a live agent trace", kill-rate line). No clipped or
    overlapping text in any frame.
- Numbers cross-checked against `media/data/verdict-good.json`
  (8/8 gates, `46/46`, `15/15`, `2224B <= 8192B`, elapsed 8 s) and
  `media/data/selftest.log` (14/14, 13 behavioural + 1 build-only).
- Automated panel bounds check: `check_inside_axes` runs in
  `fig_result.py` for terminal, gate table, and memory panels — any
  artist escaping its panel raises `RuntimeError` and fails
  `make_media.sh`.

## Notes

- The judge is unchanged. `capture.py` reuses `judge/drive.py`'s own
  `Session`/`quiet`/`FAULT_RE` machinery so the transcript is the same
  wire the judge sees; the capture's own session verdict matches the
  grade verdict (`46/46`, `15/15` for good; `5 of 46` shell + `15`
  oracle CRC failures for crc-poly).
- The video paces lines by the real capture timestamps scaled x3.4 with
  a per-line floor; quiet stretches longer than 1.4 s of display time
  collapse into a labelled `· · ·` marker rather than dead air.
