# mutants.py) is Python-standard-library only, and its interpreter is the

# mode in use) rather than slipping in unpinned.
#

# VERSIONS.txt after creating the venv; the list is exactly pip + setuptools
# (+ wheel on some CPythons), the venv's own tooling, nothing else.
