# SPEC: OpenUSD asset validation and auto-fix (traffic-cone prop)

## Goal

Demonstrate an agent-next sandbox repairing a broken OpenUSD asset until
NVIDIA's validator (`nvidia_usd_validate` from
[usd-validation-nvidia](https://github.com/NVIDIA-Omniverse/usd-validation-nvidia),
built from pinned commit `14a998c0445f33140f56879e165691c2955afca1`
"Publish public mirror v1.22.0", 2026-09-10, Apache-2.0 code / CC-BY-4.0
docs) reports zero failures, **and** an independent oracle built only on
pip `usd-core` (exact version pinned in `judge/requirements.txt`)
re-derives the same properties from scratch and confirms the repair did
not damage the geometry.

The task input is `task/traffic_cone_broken.usda`: a script-generated
prop (a 61 cm road traffic cone — square base, cone body, reflective
band; two `UsdPreviewSurface` materials; a `UsdPhysics.CollisionAPI`
collider on the body) exported from a centimetre-based DCC with six
seeded, realistic defects:

| id | defect | caught by |
|----|--------|-----------|
| D1 | no `normals` on any mesh (`subdivisionScheme = "none"`) | NVIDIA `NormalsExistChecker` (FAILURE) + oracle G2 |
| D2 | `metersPerUnit = 1` although the asset is authored in cm; `upAxis = "Z"` | oracle G2 (values, not just presence) |
| D3 | degenerate zero-area quad appended to the Band mesh | NVIDIA `ZeroAreaFaceChecker` (WARNING) + oracle G2 |
| D4 | Band mesh has no material binding | oracle G2 |
| D5 | no `defaultPrim` | NVIDIA `DefaultPrimChecker` (FAILURE) + oracle G2 |
| D6 | no `extent` authored on any mesh | NVIDIA `ExtentsChecker` (FAILURE) + oracle G2 |

The artifact is the **fixed `.usda`** the agent writes. The fix must
change metadata/topology/binding and compute normals and extents — it
must **not** move, scale or delete geometry (G3).

## Non-goals

- Rendering, textures, `.usdz` packaging, animation, rigging, instancing.
- Repair via the validator's `--fix` flag only — the oracle checks
  properties, not provenance; any correct edit path is fine.
- NVIDIA named profiles (`--profile`): the pinned commit ships **no**
  registered profiles (the CLI accepts none), so gate 1 runs the
  default rule set.
- Other USD distributions (source builds, NVIDIA Omniverse USD).

## Artifact

One ASCII USD file (`.usda`), a repaired copy of
`task/traffic_cone_broken.usda` containing:

- the same three `Mesh` prims at the same paths (`/TrafficCone/Base`,
  `/TrafficCone/Body`, `/TrafficCone/Band`), same point arrays;
- face-varying unit-length normals, one per face-corner;
- correct extent per mesh;
- root-layer metadata `metersPerUnit = 0.01`, `upAxis = "Y"`,
  `defaultPrim = "TrafficCone"`;
- a material binding on every mesh (Band → `WhitePlastic`, others →
  `OrangePlastic`);
- the collider (`UsdPhysics.CollisionAPI` on `/TrafficCone/Body`).

The known-good artifact is `examples/good/traffic_cone_fixed.usda`,
generated by `task/make_task.py` (this demo's own code, run under the
venv `judge/setup.sh` creates).

## Gates (numeric pass rules)

`judge/grade.sh <artifact.usda> [--seed N] [--json out.json]` copies the
artifact to a scratch dir, verifies `judge/` is unchanged afterwards
(sha256 before/after), and runs:

### Gate 1 — NVIDIA validator, zero failures
`nvidia_usd_validate <copy>` with the default rule set, disabling
exactly one rule, `MaterialUsdPreviewSurfaceChecker`, which cannot pass
under pip `usd-core` because the wheel ships no `shaderDefs.usda` (so
the Sdr registry resolves **no** shader id, for any asset — the rule
emits only that environmental WARNING and reports FAIL). (The earlier
draft also named `UsdShadeShaderSdrCompliance`; no rule with that name
is registered at the pinned commit and the CLI rejects it with
exit 2.) Pass rule: exit 0, JSON `status == "PASS"`, and zero issues
with severity `FAILURE` or `ERROR`.

### Gate 2 — independent usd-core oracle (`judge/oracle.py`)
Re-derives every property from the artifact using only `pxr` (no
validator code): pass rule requires **all** of
- root layer **authors** `metersPerUnit == 0.01` (the asset is in cm;
  a stage fallback default is not an authoring) and `upAxis == "Y"`;
- `defaultPrim` is authored and resolves to a prim on the stage;
- every `Mesh` prim: `len(normals) == sum(faceVertexCounts)`,
  interpolation `faceVarying`, every normal finite and unit length
  within `1e-4`;
- no face with triangle-fan area `< 1e-9` cm² (zero-area check);
- every `Mesh` has a computable bound material (`ComputeBoundMaterial`);
- every `Mesh` authors an `extent` that contains its points bbox within
  `1e-5` cm;
- at least one `Mesh` carries `UsdPhysics.CollisionAPI` (collider kept).

### Gate 3 — geometry preserved vs the original
Compared against `task/traffic_cone_broken.usda` point-by-point:
- the set of `Mesh` prim paths is identical;
- per mesh, point count is identical;
- per mesh, the bbox over authored points agrees with the original
  within `1e-6` cm per axis.

This kills "fixes" that delete offending prims or rescale the points
(e.g. multiplying by 100 and declaring `metersPerUnit = 1`).

Exit 0 only if all three gates pass; one JSON verdict; `timing` key
kept out of the deterministic body (identical seed ⇒ byte-identical
JSON except `timing`).

## Acceptance oracle

Gate 1 is the reference tool. Gate 2 is an independent recount: the
oracle re-computes normals counts, unit length, face areas (Newell /
triangle fan), extents containment, binding resolution and metadata
values with `usd-core` alone — it does not import any validator module,
so the two gates can disagree and a disagreement fails the grade.
Gate 3 is the measured invariance (point count, bbox) against the
shipped original.

## Known-bad mutants (`judge/mutants.py`)

Single edits of the good artifact: `no_normals` (D1), `mpu_1` (D2a),
`upaxis_z` (D2b), `zero_face` (D3), `unbind` (D4), `no_defaultprim`
(D5), `no_extent` (D6), `delete_band` (delete the offending prim),
`scale_points` (×100 with `metersPerUnit = 1` to fake units),
`short_normals` (drop one normal — count mismatch), and `no_collision`
(collider stripped). Self-test kill rate must be 100 % (≥ 90 %
required).
