# Simulation demo standard

Every simulation demo in `cookbook/` shows one thing: **an agent works on a real engineering problem inside a disposable agent-next sandbox, and a judge it cannot fool decides whether the result is right.** A user can run it in one command and read every result.

## Layout (`cookbook/<name>/`)

| path | what |
|---|---|
| `README.md` | one paragraph on what is simulated and why a sandbox helps; the **"Ask your agent"** prompt for plugin users; the **one-command run**; measured wall time per step; limits stated plainly |
| `SPEC.md` | goal, non-goals, the artifact the agent produces, judge gates with numeric pass rules, the acceptance oracle |
| `judge/setup.sh` | installs pinned tools idempotently into `$HOME` (exact versions; sha256-checked downloads; no `latest`, nothing published in the last two weeks) |
| `judge/grade.sh <artifact> [--seed N] [--json out.json]` | runs every gate, prints one JSON verdict, exits 0 only if all gates pass |
| `judge/selftest.sh` | proves the judge can fail: the known-good example passes; every known-bad example fails at least one gate; prints the kill rate; exits non-zero otherwise |
| `examples/good/` | a known-good artifact (written by hand or from a cited public source with licence) |
| `examples/bad/` or `judge/mutants.py` | ≥ 5 known-bad artifacts, generated by a script where possible (single-edit mutants of the good one) |
| `run.py` | the one-command run for users (below) |
| `media/` | figures + short video, see Media below |
| `RECEIPT.md` | real command output from a sandbox run: setup/selftest/grade exit codes, kill rate, key numbers, wall times, tool versions; a "Deviations" section |

## The one-command run (`run.py`)

- Python 3.10+, standard library only. Needs the `sbx` CLI (`pip install "git+https://github.com/agent-next/sandbox#subdirectory=cli"`) and `SBX_API_KEY` (or `E2B_API_KEY`) in the environment.
- Steps: `sbx create --timeout-min 30` → in the sandbox `git clone --depth 1 -b <ref> https://github.com/agent-next/sandbox` (default ref `main`, `--ref` flag to override) → `judge/setup.sh` → `judge/selftest.sh` → `judge/grade.sh examples/good/...` → print the verdict JSON and a short human summary → **always** `sbx kill` in a `finally` block, then confirm with `sbx list` that the id is gone. Non-zero exit on any failure, naming the sandbox id if cleanup could not be confirmed.
- `--keep` leaves the sandbox up and prints its id for exploration.
- Prints wall time per step.

## Judge rules

- Numeric, deterministic pass rules. A gate that "always produces a result" (e.g. a solver run) is not a judge by itself: compare against an analytic solution, a reference tool, a convergence check, or a measured spec mask.
- The self-test is mandatory and must show the judge failing on bad inputs. A judge whose kill rate is below 90 % is not done.
- Never let the artifact under test modify the judge (run it in a copy, compare checksums of `judge/` before and after).

## Media (`cookbook/<name>/media/`)

Each demo ships what a visitor needs to *see* the result without running anything:

- `media/result.png` — the key figure with the judge's pass line drawn on it (e.g. Bode plot against the spec mask, velocity profile against the analytic curve, step response inside the spec envelope, S11 against -10 dB, stress field with the allowable). Axis labels with units, a title, readable at 1200 px wide.
- `media/loop.png` — the agent loop: judge score or error per iteration until pass (from the grade JSON history), plus the self-test kill-rate bar (known-good vs each known-bad).
- `media/demo.mp4` — 20–60 s, 1280×720, H.264 (`-crf 18 -pix_fmt yuv420p`, plus `-movflags +faststart`): the simulation itself animated where the physics is time-dependent (field evolution, waveform, response), else a step-through of the agent loop's figures with captions. Rendered headless (matplotlib + ffmpeg). Under 8 MB.
- `media/MANIFEST.json` — for each file: what it shows, the command that produced it, the source data file, sha256.
- `media/make_media.sh` — regenerates every file from the judge outputs; the media must be reproducible, not hand-edited.

Figures show measured numbers only — never illustrative or invented data.

## Public-repo hygiene

This repo is public. No hostnames other than public `*.agent-next.com` endpoints, no internal paths, no keys or key-shaped placeholders (write `<your key>`), no internal plans, no names of people. Third-party code keeps its licence file and is cited with URL + version/SHA.

## Size

Keep commits small. No tool tarballs, build trees, meshes over 1 MB, or result dumps in git; `.gitignore` them. Commit the small result numbers in RECEIPT.md instead.
