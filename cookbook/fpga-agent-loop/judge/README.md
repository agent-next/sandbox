# fpga-agent-loop Judge Kit

This directory contains the judge kit for the fpga-agent-loop demo as specified in [SPEC.md](../SPEC.md).

## Contents

- `setup.sh` - Installs the pinned toolchain idempotently into `$HOME`
- `grade.sh` - Grades a CPU design against gates G0-G6
- `iss.py` - Pure Python RISC-V RV32I Instruction Set Simulator (stdlib only)
- `gen.py` - Random RV32I program generator (seeded)
- `selftest.sh` - Judge self-test as specified in SPEC.md
- `riscv_test.h` - No-CSR test header for riscv-tests
- `tests/` - Directory for prebuilt .hex test images (generated by setup.sh --rebuild-tests)
- `ref/` - Reference directory (contains picorv32 wrapper)
- `mutants/` - Directory for mutant CPU designs

## Toolchain Versions

- **OSS CAD Suite**: 2026-09-27 (yosys, nextpnr-ecp5, ecppack, verilator, iverilog)
- **RISC-V GCC**: xPack riscv-none-elf-gcc v15.2.0-1 (targets rv32i/ilp32)
- **riscv-tests**: Commit 7b68f7b91f827f8d94cc1c57ff123752c5c8f704 (September 2026)

## Usage

### Setup
```bash
bash setup.sh
source ~/.bashrc  # To update PATH
```

### Grade a CPU Design
```bash
bash grade.sh path/to/cpu.v [--seed N] [--json out.json]
```

### Run Judge Self-Test
```bash
bash selftest.sh
```

## Gates Implemented

| Gate | Description | Pass Condition |
|------|-------------|----------------|
| G0 | Lint | `verilator --lint-only -Wall` + yosys `read_verilog; proc; check -assert` (no errors) |
| G1 | ISA | riscv-tests `rv32ui` (except fence_i) with no-CSR `riscv_test.h` (all tests pass) |
| G2 | Differential | Random instruction test: Python ISS vs CPU register/memory signature (0 mismatches) |
| G3 | Trap | Directed tests: illegal opcode, ECALL, EBREAK, misaligned LW/SW/jump → trap rises |
| G4 | Bus | Memory model with randomized `mem_ready` latency (0-7 cycles, seeded) |
| G5 | Synthesis | yosys `synth_ecp5` + nextpnr-ecp5 `--85k --package CABGA381` (P&R succeeds) |
| G6 | Performance | Cycles for fixed benchmark (bubble sort) under 0-latency memory (reported CPI) |

## Self-Test

The judge self-test (`selftest.sh`) verifies that the judge can correctly:
1. Pass a known-good control (YosysHQ/picorv32 with specified wrapper)
2. Fail known-bad controls (≥20 single-edit mutants, each failing ≥1 gate)
3. Validate the ISS as an oracle (agrees with picorv32 on 1,000 random programs)

See `SELFTEST-RECEIPT.md` for results from running the self-test in this sandbox.
