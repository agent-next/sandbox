# fpga-agent-loop Judge Kit

This directory contains the judge kit for the fpga-agent-loop demo as specified in [SPEC.md](../SPEC.md).

## Contents

- `setup.sh` - Installs the pinned toolchain idempotently into `$HOME/riscv-toolchain` (sha256-verified; `--rebuild-tests` regenerates `tests/*.hex` from source)
- `grade.sh` - Grades a CPU design against gates G0-G6 (G0/G1/G2/G3/G4 working; G5/G6 SKIP, see "Status" below)
- `tb.cpp` - Verilator testbench: 64 KiB RAM, tohost at 0x10000000, trap detection, seeded random `mem_ready` latency 0-7
- `iss.py` - Pure Python RISC-V RV32I Instruction Set Simulator (stdlib only; G2 oracle)
- `gen.py` - Random RV32I program generator (seeded, byte-identical output; used by G2)
- `g2check.py` - G2 driver: runs each generated program on the Verilator DUT and the ISS, compares the x1..x31 signature
- `gen_traps.py` - Generates the directed trap programs in `tests/trap/` (G3)
- `mutants.py` - Single-edit mutants of the fetched picorv32.v for the power test (6 shipped: 3 T1 + 3 T2, >= 20 in T3); writes to `mutants_out/`
- `riscv_test.h` - No-CSR test header for riscv-tests
- `tests/` - Prebuilt .hex test images (riscv-tests rv32ui, no-CSR build)
- `tests/trap/` - Directed trap programs (generated by `gen_traps.py`)
- `ref/picorv32_cpu.v` - SPEC-interface wrapper around the pinned picorv32 (known-good control)
- `selftest.sh` - Judge self-test as specified in SPEC.md (lands in T3)
- `T1-RECEIPT.md` - Real pasted output for the T1 runs (setup, reference grade, mutant grades)
- `T2-RECEIPT.md` - Real pasted output for the T2 runs (ISS check, G2 on picorv32, 1000-program ISS agreement, G2 power-test mutants)

## Usage

### Setup
```bash
bash setup.sh              # idempotent; sha256-checks every download
bash setup.sh --rebuild-tests   # regenerate tests/*.hex from source
```

### Grade a CPU Design
```bash
bash grade.sh path/to/cpu.v [--seed N] [--json out.json] [--g2-count K]
```
`--g2-count K` shrinks G2 to K random programs (default: the SPEC's 200,
each 500 instructions) for quick iterations.

### Grade a Mutant (power test)
```bash
python3 mutants.py
PICORV32_DIR=$PWD/mutants_out/<name> ./grade.sh ref/picorv32_cpu.v
```

### Run Judge Self-Test
```bash
bash selftest.sh
```

## Status (after T2)

| Gate | Description | Status |
|------|-------------|--------|
| G0 | Lint: `verilator --lint-only -Wall` + yosys `read_verilog; proc; check -assert` (no errors; warnings allowed) | **working** |
| G1 | ISA: riscv-tests `rv32ui` (40 tests, no-CSR `riscv_test.h`, fence_i/ma_data excluded) with the seeded random latency | **working** |
| G2 | Differential: seeded random programs (`gen.py`) on the DUT vs the Python ISS (`iss.py`/`g2check.py`); x1..x31 signature must match. SPEC default 200 programs x 500 instructions (`--g2-count` for quick runs) | **working** |
| G3 | Trap: directed tests (illegal opcode, ECALL, EBREAK, misaligned LW/SW/jump) assert trap and the bus goes quiet | **working** |
| G4 | Bus: G1 re-run under 3 more latency seeds (mem_ready latency 0-7, seeded) | **working** |
| G5 | Synthesis: yosys `synth_ecp5` + nextpnr-ecp5 `--85k --package CABGA381` | SKIP (T3) |
| G6 | Performance: cycles for a fixed benchmark under 0-latency memory (reported CPI) | SKIP (T3; not a gate) |

`grade.sh` exits 0 only if every non-skipped gate passes; skipped gates and
their reasons are recorded in the JSON verdict.

- [T2-RECEIPT.md](T2-RECEIPT.md): the ISS reports tohost==1 on all 40

  G1 40/40 yet are killed by G2.

## Self-Test

The judge self-test (`selftest.sh`) verifies that the judge can correctly:
1. Pass a known-good control (YosysHQ/picorv32 with specified wrapper) — done in T1
2. Fail known-bad controls (≥20 single-edit mutants, each failing ≥1 gate) — T1+T2 ship 6 killed mutants via `mutants.py` (including 2 that pass G1 and die only on G2); the full >= 20 set and the `selftest.sh` driver land in T3
3. Validate the ISS as an oracle (agrees with picorv32 on 1,000 random programs) — done in T2 (1000/1000, see T2-RECEIPT.md)

No `SELFTEST-RECEIPT.md` exists yet; the evidence lives in
[T1-RECEIPT.md](T1-RECEIPT.md) and [T2-RECEIPT.md](T2-RECEIPT.md).
