# fpga-agent-loop Judge Kit

This directory contains the judge kit for the fpga-agent-loop demo as specified in [SPEC.md](../SPEC.md).

## Contents

- `setup.sh` - Installs the pinned toolchain idempotently into `$HOME/riscv-toolchain` (sha256-verified; `--rebuild-tests` regenerates `tests/*.hex` from source)
- `grade.sh` - Grades a CPU design against gates G0-G6 (G0/G1/G3/G4 working; G2/G5/G6 SKIP, see "Status" below)
- `tb.cpp` - Verilator testbench: 64 KiB RAM, tohost at 0x10000000, trap detection, seeded random `mem_ready` latency 0-7
- `iss.py` - Pure Python RISC-V RV32I Instruction Set Simulator (stdlib only; used by G2 in T2)
- `gen.py` - Random RV32I program generator (seeded; used by G2 in T2)
- `gen_traps.py` - Generates the directed trap programs in `tests/trap/` (G3)
- `mutants.py` - Single-edit mutants of the fetched picorv32.v for the power test (3 in T1, >= 20 in T3); writes to `mutants_out/`
- `riscv_test.h` - No-CSR test header for riscv-tests
- `tests/` - Prebuilt .hex test images (riscv-tests rv32ui, no-CSR build)
- `tests/trap/` - Directed trap programs (generated by `gen_traps.py`)
- `ref/picorv32_cpu.v` - SPEC-interface wrapper around the pinned picorv32 (known-good control)
- `selftest.sh` - Judge self-test as specified in SPEC.md (lands in T2/T3)
- `T1-RECEIPT.md` - Real pasted output for the T1 runs (setup, reference grade, mutant grades)

## Toolchain Versions

- **OSS CAD Suite**: 2026-09-27 (yosys, nextpnr-ecp5, ecppack, verilator, iverilog)
- **RISC-V GCC**: xPack riscv-none-elf-gcc v15.2.0-1 (targets rv32i/ilp32)

## Usage

### Setup
```bash
bash setup.sh              # idempotent; sha256-checks every download
bash setup.sh --rebuild-tests   # regenerate tests/*.hex from source
```

### Grade a CPU Design
```bash
bash grade.sh path/to/cpu.v [--seed N] [--json out.json]
```

### Grade a Mutant (power test)
```bash
python3 mutants.py
PICORV32_DIR=$PWD/mutants_out/<name> ./grade.sh ref/picorv32_cpu.v
```

### Run Judge Self-Test
```bash
bash selftest.sh
```

| G0 | Lint: `verilator --lint-only -Wall` + yosys `read_verilog; proc; check -assert` (no errors; warnings allowed) | **working** |

| G3 | Trap: directed tests (illegal opcode, ECALL, EBREAK, misaligned LW/SW/jump) assert trap and the bus goes quiet | **working** |
| G4 | Bus: G1 re-run under 3 more latency seeds (mem_ready latency 0-7, seeded) | **working** |

| G6 | Performance: cycles for a fixed benchmark under 0-latency memory (reported CPI) | SKIP (T3; not a gate) |

`grade.sh` exits 0 only if every non-skipped gate passes; skipped gates and
their reasons are recorded in the JSON verdict.

Verified end-to-end (see [T1-RECEIPT.md](T1-RECEIPT.md) for pasted output):
the known-good control `ref/picorv32_cpu.v` passes G0/G1/G3/G4 (exit 0,
~11 s), and all 3 T1 mutants (branch-flip, wstrb-lane-drop,
ignore-mem-ready) are killed with exit 1 via G1/G4.

## Self-Test

The judge self-test (`selftest.sh`) verifies that the judge can correctly:
1. Pass a known-good control (YosysHQ/picorv32 with specified wrapper) — done in T1
2. Fail known-bad controls (≥20 single-edit mutants, each failing ≥1 gate) — T1 ships 3 killed mutants via `mutants.py`; the full set and the `selftest.sh` driver land in T2/T3
3. Validate the ISS as an oracle (agrees with picorv32 on 1,000 random programs) — T2

No `SELFTEST-RECEIPT.md` exists yet; the T1 evidence lives in
[T1-RECEIPT.md](T1-RECEIPT.md).
