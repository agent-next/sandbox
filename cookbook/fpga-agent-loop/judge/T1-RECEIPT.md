## 3. Power test — hand-broken mutants (criterion 4)

Mutants are single (search, replace) edits on the sha256-checked
`~/riscv-toolchain/picorv32/picorv32.v`, generated by `judge/mutants.py`:

```
$ python3 mutants.py
wrote .../mutants_out/branch-flip/picorv32.v  (BEQ/BNE conditions swapped: rv32ui branch tests must fail (G1))
wrote .../mutants_out/wstrb-lane-drop/picorv32.v  (SW drops byte lane 0: every full-word store corrupts memory (G1))
wrote .../mutants_out/ignore-mem-ready/picorv32.v  (mem_ready ignored: only survives if the tb never stretches a request - G4's random latency must break it)
3 mutants written to .../mutants_out
```

Each mutant is graded by shadowing the include path:
`PICORV32_DIR=$PWD/mutants_out/<name> ./grade.sh ref/picorv32_cpu.v`.
Every gate result below is a real paste; repetitive per-test FAIL lines are
elided with counts.
