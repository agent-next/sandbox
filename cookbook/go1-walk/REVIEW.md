# Always check

- A POST with an ambiguous 5xx reply is not safe to repeat. Retry only an
  explicit pre-execution capacity rejection or a busy-slot conflict.
- Validate lease ids before storing them or constructing any cleanup URL.
- Validate required negative artifacts before spending time on training.
- Advanced-indexed state writes must reach the live simulation tensor.
- Timings are elapsed durations. Preserve cumulative kernel setup across
  training chunks, separately from training throughput.
- CPU judge and Warp trainer must share the documented observation scales.
- Grading must simulate, not read claimed artifact results. A judge error
  is not a numeric mutant kill.
- Media must use exact judge states, visible 3D geometry and physics-neutral
  scene dressing. Never choose episodes after seeing a flattering result.
