# Pinned, hash-checked pytest wheels for the ci-test-matrix demo.
#
# One `uv pip install --require-hashes -r requirements.txt` per matrix cell,
# into that cell's own uv venv.  Every requirement is hash-pinned, so a
# changed or re-uploaded artifact on PyPI fails the install loudly instead
# of silently changing the test framework under the judge.
#
# Per-version notes:
#   * pytest's only platform-specific dependency is colorama (win32 only);
#     it is pinned so the file does not change on a Windows cell.
#   * exceptiongroup (needed on <3.11) and tomli (needed on <3.11) are
#     pinned for every version so one file serves all five cells.
#   * Each entry lists the pure-python wheel and the sdist; both are the
#     digests PyPI publishes for those files.
#
# Verified by installing into a fresh venv per interpreter:
#   for v in 3.9.25 3.10.21 3.11.16 3.12.14 3.13.15; do
#       uv venv --python "$v" /tmp/v && \
#           uv pip install --python /tmp/v/bin/python --require-hashes \
#               -r judge/requirements.txt || echo "FAIL $v"; done
# (all five install; see judge/VERSIONS.txt).
