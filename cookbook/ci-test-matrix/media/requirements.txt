# manylinux x86_64 -- every distribution is pinned, so the resolved set is
# the same on every machine.  Resolved and installed on the acceptance run
# of 2026-10-15; the installed versions are recorded in MANIFEST.json.
#
# matplotlib 3.10.5 is older than two weeks at that date, so it is not a
# "latest" pin.
