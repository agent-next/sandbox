# media/REVIEW.md — what was checked before committing the media

All media is generated by `bash media/make_media.sh` from real judge output
(verdict JSONs and `--trace` directories of actual icoFoam runs, seed 42).
Nothing is hand-edited.

Environment: matplotlib 3.8.4 / numpy 2.0.2 / pillow 11.1.0 in the
hash-pinned venv (`/tmp/ofmedia`, installed with `--require-hashes -r
judge/requirements.txt`); OpenFOAM 1912.200626-1+b1 installed via
`judge/setup.sh` (23 pinned, sha256-verified debs); node v24.21.0 with
Remotion 4.0.531 (`npm ci` from the committed `video/package-lock.json`);
ffmpeg 5.1.9-0+deb12u1. Invoked as
`PYTHON=/tmp/ofmedia/bin/python bash media/make_media.sh`.

## 2. Images opened at full size

**result.png** (4 panels, opened at 2560×1920):

- (a) Poiseuille u(y): measured dashed blue vs analytic orange, 2 % band
  visible, legend upper-left, PASS box (L2 error = 0.0043 ≤ 0.02) clear of
  the curves. Gate 3.
- (b) Cavity centrelines vs Ghia 1982 open markers, legend inside axes not
  covering data, PASS box (max u err 0.0033, v err 0.0073 ≤ 0.02). Gate 5.
- (c) Mesh convergence log-log: three L2 points, fitted slope 2.15, red
  dotted gate-3 pass line at 0.02 with arrow-labelled text, no collision
  with title (ylim padded for it). Gate 4.
- (d) Cavity |U| scatter at t = 30 s: lid band dark at top, vortex eye near
  centre, sequential blue ramp, colorbar labelled. Physical assert (`top >
  0.8` in the lid band) passes inside make_figures.py, so field/centre
  pairing is right, not just plausible-looking.
- Suptitle, panel titles, all axis labels: nothing clipped or overlapping.

**loop.png** (2 panels, opened at 2560×1080):

- (a) Replayed agent loop: bars are the gate-5 metric (max centreline error
  vs Ghia, % of lid speed) for each replayed iteration — step 1 wrong lid
  50.0 % FAIL gate 5, step 2 unconverged 14.1 % FAIL gates 2,5, step 3
  coarse mesh FAIL gate 5, step 4 fixed PASS at 0.73 % under the dashed
  gate-5 pass line at 2 %. FAIL/PASS tags sit above their bars without
  touching the pass line; the pass-line annotation is arrow-pointed into
  empty space. Labels state the gate each step failed (from the verdict
  JSONs, not guessed).
- (b) Self-test kill rate: 10/10 blue bars at 100 %, "killed" tags right of
  every bar, title "(above: required >= 90 %)". Grey background bars show
  the full 0–100 % range.
- Colors: series blue #2a78d6 / orange #eb6834, status green #0ca30c /
  red #d03b3b (validated palette); text in ink, not series colors.

  |U| picture-in-picture at t = 20 s.

  HUD chips (L2 0.0043/0.02, orders 2.15/1.91, Ghia u 0.0033 v 0.0073,
  kills 10/10, residual gauge) over still-moving footage.

No frame is text-only, a still plot, or a blank background; every overlay
sits on moving solver output except the last-2.5 s static end card.
