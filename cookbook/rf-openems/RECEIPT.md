## 4. Determinism

openEMS on this build is not bit-deterministic (same sim exits its decay
loop a few timesteps apart; floats wander ~1e-4 relative). The verdict
therefore reports sim-derived numbers on a stated grid (1 dB / 0.01 GHz /
0.1 % / 1 deg) while gate decisions keep raw values — see SPEC.md.
selftest.sh grades the good artifact twice with the same seed and compares
JSON minus `timing`:

```
== determinism check (two runs, timing stripped) ==
  deterministic: yes
```

## Deviations

  agent/model family; stub records the required tolerances.
- `media/` skipped per task instructions (another agent owns media).

  PyPI JSON API instead — same guarantee.

  still use raw values. Documented in SPEC.md.

  use); fixed by excluding generated files from the integrity hash and
  rerun cleanly.
