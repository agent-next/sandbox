# SPEC — `cookbook/video-transcode-pipeline/`

An agent works on a real media-processing problem inside a disposable
agent-next sandbox: take an uploaded test video, produce an HLS
transcode ladder plus burned-in frame counters, a poster frame, and
WebVTT captions from speech, where a judge it cannot fool (ffmpeg/ffprobe
+ a stdlib-only oracle: frame-counter decode + caption WER against
known text) decides whether the result is right.

## Goal

Design and fix one `pipeline.sh` that ingests an uploaded MP4 and emits:

- HLS renditions 360p and 720p (H.264 + AAC) with 2-second segments,
  keyframe interval of 4 seconds (±1 %), containing the burned frame
  counter from the source;
- a poster PNG (single frame from t=1 s);
- WebVTT captions transcribed from the clip's speech track.

The judge must be able to catch a pipeline that "runs fine" but emits
wrong resolutions, truncated output, dropped frames, blank posters, or
empty/wrong captions.

## Non-goals

- Audio quality (loudness, codecs beyond AAC-LC), DRM, ABR bitrate
  ladders beyond the two required renditions, live input.
- Caption *translation*, speaker diarisation, or caption styling
  (position, colour). Only text + timing matter.
- Whether the pipeline is idempotent or restartable; it runs once.
- Optimality: no reward for margin beyond the pass rules.

## Artifact

`pipeline.sh` — a bash script run inside the demo dir as:

```bash
./pipeline.sh --input <uploaded.mp4> --out <output-dir> --seed <N>
```

It reads fixtures from `fixtures/` (see below) unless `--input` is given
a custom file, and writes everything under `<output-dir>`:

```
out/
  360p/index.m3u8  360p/seg-*.ts
  720p/index.m3u8  720p/seg-*.ts
  poster.png
  captions.vtt
```

The script must be deterministic for a given seed (the seed selects
caption wording variants only where the pipeline introduces randomness;
the known-good path uses the default seed and produces byte-stable
numbers).

### Fixtures (generated by `fixtures/gen_fixtures.sh`, committed)

- `fixtures/source.mp4` — 20 s, 640×360, 24 fps, H.264 + AAC: a
  `testsrc` video with a **burned-in frame counter** (bottom-left,
  `%{n}` via `drawtext`) and a tone. Generated by ffmpeg only.
- `fixtures/speech.mp3` — 6 s speech clip whose transcript is the
  *known text* `SPEECH_TEXT` (one line, cited public-domain recording
  or espeak-ng-rendered if a recording is unavailable).

The judge never generates the fixtures; they are committed inputs.

## Judge gates (`judge/grade.sh <artifact> [--seed N] [--json out.json]`)

All gates numeric and deterministic. Exit 0 only if all pass.

- **G1 runs**: `pipeline.sh` exits 0 within 300 s (2 vCPU) and creates
  every required file under `<out>`.
- **G2 rendition geometry**: each HLS rendition's first `.ts` segment and
  its concatenated stream report (via `ffprobe` on a probe-concat of
  the segments) exactly 360p (640×360) / 720p (1280×720) width and
  height, and codec `h264` + `aac`.
- **G3 duration**: total HLS duration (from the `.m3u8` `#EXT-X-ENDLIST`
  and segment durations) is within **0.1 s** of the source duration
  (20.0 s) for both renditions.
- **G4 keyframe interval**: every rendition has keyframes whose gaps are
  within 4 s ±1 % (48 frames at 24 fps), and at least 4 keyframe gaps
  per rendition.
- **G5 no dropped frames**: the judge burns no counter; the *source's*
  burned counter is decoded back from the **renditions** at sampled
  timestamps (t = 0.5, 1, 2, … 19.5 s). At each sample the counter value
  read from the rendition must equal `round(t * 24)` ± 2 (counter
  tolerance for encoder re-time). Fewer than **95 %** of samples
  matching fails. (This is the "dropped segment" detector: a gap in
  segments shifts all later counter reads.)
- **G6 poster**: `poster.png` exists, is at least 100×100 px, and is
  **not blank** — stdlib PNG decode shows the fraction of distinct
  luminance values ≥ 5 % and the centre pixel luminance is not the
  background value (testsrc centre is not black).
- **G7 captions present**: `captions.vtt` parses as WebVTT (header
  `WEBVTT`, ≥ 4 cue blocks with timestamps `HH:MM:SS.mmm -->
  HH:MM:SS.mmm`), covers ≥ 80 % of the speech clip's timeline, and is
  not empty.
- **G8 caption accuracy (WER)**: word error rate of the caption text
  (all cue payload lines concatenated, normalised: lowercase,
  strip punctuation) against the known `SPEECH_TEXT` is ≤ **0.20**
  (20 %). This is the oracle: the known text is the ground truth, and
  the gate is a *computed* comparison, not "the file exists".

## Acceptance oracle (independent of "the tool ran")

1. **Known-text WER**: the judge hard-codes the speech clip's
   transcript (`SPEECH_TEXT` in `judge/grade.sh`, identical to
   `fixtures/TRANSCRIPT.txt`) and computes WER = (S+D+I)/N over
   normalised words. A pipeline that emits empty or wrong captions
   fails here; one that copied the transcript *without running
   transcription* would also pass — so the judge additionally checks
   (G7) that the caption cue count ≥ 4 and the clip was actually
   transcribed by a model whose output the judge validates as
   *consistent*: the caption text must not equal the transcript file
   byte-for-byte while the `.vtt` has fewer than 3 cues (an echo of the
   source). (The known-good example runs real whisper.cpp.)
2. **Frame-counter decode**: the oracle reads the burned counter from
   the rendition pixels at each sampled timestamp (stdlib PNG decode of
   the raw RGB frame dumped via ffmpeg → PPM → judge-side parse) and
   compares against the analytic `round(t*24)` — an independent,
   per-frame expected value, not a property of the pipeline output.
3. **Keyframe interval** measured from `ffprobe -skip_frame nokey`
   PTS times, not from the `.m3u8`.
4. **Monte-Carlo / reproducibility**: with a fixed seed the pipeline
   verdict is deterministic — two `grade.sh` runs with the same seed
   produce byte-identical verdict JSON (excluding `timing`).

## Self-test (`judge/selftest.sh`)

- The known-good artifact passes all gates.
- ≥ 5 known-bad **single-edit mutants** of the good artifact each fail
  ≥ 1 gate, generated by `judge/mutants.py` (one edit each):
  - `wrong-resolution` (720p → 1280×960),
  - `truncated` (cut renditions to 10 s),
  - `dropped-segment` (drop a middle segment from the 360p
    `index.m3u8` but keep all `.ts` files),
  - `empty-captions` (write `WEBVTT` + one empty cue),
  - `wrong-keyframe` (keyframe interval 8 s instead of 4 s).
- Kill rate ≥ 90 % printed; exit non-zero otherwise.
- Determinism: two `grade.sh` runs with the same seed produce
  byte-identical verdict JSON; checked every run.

## Judge-integrity rule

The artifact under test is copied to a temp dir before grading; the
judge compares `sha256` of its own `judge/` tree before and after
grading and fails closed if anything changed.

## Out of scope for the judge

- Audio loudness/AQ beyond "AAC present, decodable".
- HLS authoring style beyond the required files; segment naming.
- Anything the script claims in comments.

- Python ≥ 3.10, stdlib only, for the judge math.
